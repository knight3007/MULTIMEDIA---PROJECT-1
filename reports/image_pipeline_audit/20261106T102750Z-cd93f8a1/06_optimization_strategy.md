# Accuracy optimization strategy

## Evidence-led ranking

| Option | Expected benefit | Risk / cost | Evidence requirement | Rank |
|---|---|---|---|---:|
| Human-label and test a target-sense-aware Qwen prompt, preserving the current model | High for 17 current selected IDs with an observable query-stage problem; directly addresses `today timepiece`, `yesterday place`, `study object` | Low technical risk; no media mutation. Review time is required. | Paired query correctness labels on a fixed difficult subset | 1 |
| Persist full DDGS candidate and score evidence in a future isolated benchmark | High diagnostic value for 32 flagged images whose first failure stage is unknown | Moderate storage, metadata and rights handling; no benefit without labels | Candidate URLs, byte hashes, scores, human relevance labels | 2 |
| Broaden Bing/DDGS retrieval from 3 to more results | Possible recall gain if suitable images are absent from top 3 | More latency, 403/429 exposure, stock previews and license work; not proven by current data | Recall@K from a saved candidate pool | 3 |
| Add a visual verification/rejection stage | Possible precision gain after retrieval | Additional model, compute and decision thresholds; false rejects likely | Labeled current and alternative candidates | 4 |
| Replace SigLIP2 with another CLIP/OpenCLIP ranker | Unknown local gain | Model download/VRAM/integration and benchmark cost | Same fixed candidate pool scored by both models, human top-K labels | 5 |

## Current model and pipeline diagnosis

`query_generator.py` sends only the English word to `Qwen/Qwen3-1.7B`; the owner-approved target sense, Japanese written form and Vietnamese gloss are not in the prompt. The system prompt strongly prefers a noun plus semantic class. This produces syntactically valid but semantically poor phrases for temporal words, verbs, adjectives and abstract words. The parser rejects explicit meta words such as `verb`, yet accepts `study object` or `today timepiece`. The current cache signature covers the ordered vocabulary, model ID, prompt text and generation settings; any prompt experiment must use a **new** cache/version. The [official Qwen3-1.7B model card](https://huggingface.co/Qwen/Qwen3-1.7B) lists Apache-2.0 for the model; it says nothing about rights to retrieved images. The exact local model revision was not persisted.

`imagecollector.py` requests at most three Bing results per generic ID, filters unsafe/duplicate URLs, downloads usable candidates and picks the largest SigLIP2 logit. It does not require a minimum score. Negative values therefore can still win, as shown by `swim` and `rain`; a positive value can also win an unsuitable text-heavy asset. The raw logit is not a probability. The scorer's text is the **effective search query**, not the Japanese/Vietnamese meaning or an independently written image description. Its processor decodes RGB images and pads text; the selected candidate is normalized only after ranking. The local SigLIP snapshot is `dd658faac399427308559e2c3ac1e99cbe43845d`; current `.venv` has PyTorch 2.14.0+cu132 and Transformers 5.17.0, and this machine has a 4 GiB GTX 1650. The [official SigLIP2 model card](https://huggingface.co/google/siglip2-so400m-patch16-384) lists Apache-2.0; the [SigLIP2 paper](https://arxiv.org/abs/2502.14786) reports improved image-text retrieval against earlier SigLIP checkpoints in its benchmarks. Neither source establishes accuracy for this project's 100 words or rights to Bing images.

An alternative CLIP/OpenCLIP model is **not recommended for implementation now**. There is no retained candidate pool or human relevance set on which to show it beats the current model. A vision-language verifier is likewise premature; it may catch wrong referents but would add model loading and cost before the retrieval-versus-ranking bottleneck is known. This audit did not install, download or benchmark any model.

## One smallest next experiment

Run a **query-only paired evaluation on the fixed 25 IDs in `06_benchmark_design.md`**. Keep Qwen3-1.7B and decoding settings fixed. Compare the saved baseline parsed query with a new versioned prompt that includes the canonical EN/JP/VN triple, approved target sense where available, and a requested visible depiction. Save raw and parsed outputs in a separate diagnostic run, with no DDGS, downloads or SigLIP. Have the owner or a bilingual reviewer label whether each query unambiguously represents the intended learning meaning, blind to prompt variant. This tests whether changing prompt/context fixes the most direct observed failure mode without destroying current results. It cannot yet measure final image accuracy; the next benchmark stage should retain and label candidates before changing the ranker.
