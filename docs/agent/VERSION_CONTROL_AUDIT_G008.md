## Git LFS

**Not recommended now.** The largest file is 5.5 MB, the total is about 30 MB raw (about 8 MB compressed), and the fonts are stable. LFS would add a GitHub storage and bandwidth quota (1 GB free) and an install step for every clone, for no real gain.

The new narrow `game/New Unity Project/.gitattributes` instead:
- keeps Unity YAML at LF (`*.unity/*.prefab/*.asset/*.mat/*.meta/*.shadergraph/*.asmdef`), with `merge=unityyamlmerge` used if that driver is configured;
- marks the TMP SDF atlases `-diff linguist-generated`;
- marks `*.ttf/*.otf/*.png/*.ogg` as `binary`.

It was verified with `git check-attr`, and the existing files are already LF, so there is no churn. No root `.gitattributes` was added, so existing tracked files are not renormalized. Reconsider LFS only if large audio, video or textures enter `Assets/`.

## Reconstruction from a clone

1. Install Unity 6000.6.10f1 (`ProjectSettings/ProjectVersion.txt`). Open `game/New Unity Project`. `Library/` is regenerated and packages resolve from the lock file.
2. Scenes and fonts are tracked, so the project builds immediately. `BatchBuild.RebuildScenes` can regenerate the scenes.
3. Tests: run `Tools/headless.ps1` with `UNITY_EDITOR_EXE` set if needed.
4. **External Content Packs (not in Git).** The playable vocabulary is the reviewed v47 pack: a manifest plus 45 MP3/JPG assets, 1.6 MB. Its media are generated by the private pipeline and are ignored by the root rules. To restore it:
   - copy an archive of `reports/EXCEL_15_SMOKE/run-bc2d5460-…/` (v46 and `content_pack_v47_reviewed`) from the owner's machine or a private backup into the same path; or
   - place a pack in `%USERPROFILE%/AppData/LocalLow/MultimediaProject1/Word Orbit G-003 Prototype/ContentPacks/`; or
   - regenerate it through the Docker pipeline (`docs/DOCKER_PIPELINE.md`) and promote it with `collect data script/promote_reviewed_pack.py`. Regenerated media will differ byte for byte, so this needs a new owner review.
   - Recommendation: keep a private archive (ZIP) of v46 and v47 outside Git. Its SHA-256 values are recorded in HANDOFF.
5. `game/UXUI/` is only needed to re-import or replace art. The original Kenney and Noto packs are public downloads (ASSET_SOURCES.md lists the pack names).
